# Ejemplos de Outputs

Esta carpeta contiene ejemplos de outputs previos del proyecto de scouting de innovación de Applus.

## Tipos de Ejemplos
- **`propuestas/`** - Propuestas de innovación exitosas (movidas a `outputs/propuestas/`)
- **`informes/`** - Informes de investigación completados
- **`emails/`** - Comunicaciones efectivas
- **`presentaciones/`** - Presentaciones ejecutivas

## Propósito
Los ejemplos sirven para:
- Mantener consistencia en outputs
- Proporcionar referencias de calidad
- Entrenar modelos de IA
- Establecer estándares del proyecto

## Uso con IA
- Referencia para generar nuevos outputs
- Base para análisis comparativo
- Ejemplos de mejores prácticas
- Patrones de éxito identificados

## Nota Importante
Los archivos de propuestas (`Scouting innovacion.md` y `Propuesta_Scouting_IA.md`) se han movido a `outputs/propuestas/` para mejor organización del proyecto.
