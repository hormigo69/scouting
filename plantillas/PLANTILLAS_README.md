# Plantillas del Proyecto

Esta carpeta contiene plantillas reutilizables para el proyecto de scouting de innovación de Applus.

## Plantillas Disponibles
- `reunion.md` - Plantilla para reuniones
- `propuesta.md` - Plantilla para propuestas de innovación
- `informe.md` - Plantilla para informes de investigación
- `email.md` - Plantilla para comunicaciones por email

## Uso
1. Copiar la plantilla correspondiente
2. Personalizar con información específica del proyecto
3. Seguir las reglas de estilo definidas en `reglas/REGLAS_ESTILO_IA.yaml`
4. Revisar con IA usando enfoque adversarial

## Personalización
Cada plantilla incluye:
- Estructura estándar
- Secciones requeridas
- Ejemplos de contenido
- Instrucciones de uso
