# Documentación del Proyecto

Esta carpeta contiene toda la documentación del proyecto de scouting de innovación de Applus.

## Estructura
- **`docs_tecnicos/`** - Documentación técnica del proyecto y APIs de terceros
- **`transcripciones/`** - Transcripciones de reuniones y sesiones

## Contenido Principal
- `PERFIL_CORPORATIVO_APLUS.md` - Información corporativa y modelo de negocio
- `ARQUITECTURA_SISTEMA_IA.md` - Arquitectura y especificaciones del sistema de IA
- `Applus Presentación Corporativa 2024.pdf` - Presentación corporativa actualizada
- `Market Map y Perfil de Compañia.pdf` - Material de referencia de mercado

## Uso
- **Referencia**: Consultar información corporativa y técnica del proyecto
- **Contexto**: Proporcionar base de conocimiento para el equipo
- **Análisis**: Usar como fuente para análisis y propuestas
- **IA**: Entrenar modelos con información estructurada del proyecto

## Mantenimiento
- Actualizar documentación técnica cuando cambien especificaciones
- Mantener transcripciones de reuniones actualizadas
- Revisar y actualizar información corporativa según sea necesario
