# Documentación Técnica

Esta carpeta contiene la documentación técnica del proyecto de scouting de innovación de Applus.

## Contenido
- `especificaciones.md` - Especificaciones técnicas del proyecto
- `arquitectura.md` - Arquitectura del sistema de IA
- `metodologia.md` - Metodología de scouting
- `herramientas.md` - Herramientas y tecnologías utilizadas
- `API_PITCHBOOK_GUIA.md` - Documentación técnica de la API de Pitchbook
- `Pitchbook API V2 Endpoints.xlsx` - Lista de endpoints disponibles de la API
- `Pitchbook API V2 Sandbox Entities.xlsx` - Entidades disponibles en sandbox

## Estándares
- Formato: Markdown para archivos de texto, Excel para especificaciones técnicas
- Estructura: Headers claros y lógica
- Incluir: Diagramas, ejemplos y referencias

## Integración con IA
La documentación técnica se utiliza para:
- Entrenar modelos de IA
- Generar outputs consistentes
- Mantener contexto del proyecto
- Facilitar colaboración del equipo
- Proporcionar especificaciones técnicas para integraciones con APIs de terceros
