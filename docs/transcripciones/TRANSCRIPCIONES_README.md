# Transcripciones de Reuniones

Esta carpeta contiene las transcripciones de reuniones relacionadas con el proyecto de scouting de innovación de Applus.

## Estructura
- `reunion_inicial.md` - Primera reunión de definición del proyecto
- `reunion_estado.md` - Reuniones de seguimiento del estado
- `reunion_revision.md` - Reuniones de revisión de outputs

## Formato
Cada transcripción debe incluir:
- Fecha y hora
- Participantes
- Agenda
- Notas detalladas
- Preguntas clave
- Acciones acordadas

## Uso con IA
Las transcripciones se utilizan para:
- Extraer requisitos clave
- Generar resúmenes ejecutivos
- Identificar oportunidades y riesgos
- Crear propuestas basadas en evidencia
