# Propuestas del Proyecto

Esta carpeta contiene las propuestas generadas para el proyecto de scouting de innovación de Applus.

## Contenido

### Análisis del Estado Actual
- **`Scouting innovacion.md`** - Documento que describe el proceso actual de scouting de innovación, incluyendo el flujo de trabajo, herramientas utilizadas y áreas de mejora identificadas.

### Propuestas de Mejora
- **`Propuesta_Scouting_IA.md`** - Propuesta completa para implementar un sistema inteligente de scouting de innovación potenciado por IA, incluyendo arquitectura, funcionalidades y plan de implementación.
- **`Propuesta_Piloto_Scouting_IA_Fases_2_3.md`** - Propuesta específica para un piloto (MVP) que se centra en las fases 2 y 3 del sistema completo, con alcance limitado para validación rápida.

### Diagramas y Visualizaciones
- **`Diagrama de Arquitectura de Agentes.png`** - Diagrama que muestra la arquitectura del sistema de agentes IA para el scouting de innovación.
- **`Diagrama de Flujo.png`** - Diagrama de flujo del proceso de scouting asistido por IA.
- **`DIagrama arquitectura piloto.png`** - Diagrama específico de la arquitectura del piloto MVP.

## Uso

### Para el Equipo de Innovación
- **Referencia**: Consultar el estado actual del proceso
- **Mejora**: Analizar propuestas de optimización
- **Planificación**: Usar como base para futuras implementaciones
- **Visualización**: Comprender la arquitectura y flujo del sistema propuesto

### Para Stakeholders
- **Entendimiento**: Comprender el proceso actual y las oportunidades de mejora
- **Decisión**: Evaluar propuestas de inversión en tecnología
- **Alineación**: Asegurar que las mejoras se alineen con objetivos estratégicos
- **Comunicación**: Usar diagramas para explicar el sistema a diferentes audiencias
